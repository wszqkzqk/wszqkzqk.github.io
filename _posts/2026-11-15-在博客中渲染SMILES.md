## 前言

本站此前使用MathJax和mhchem排版化学式，例如`$\ce{H2O}$`可以显示为$\ce{H2O}$。mhchem负责化学式的排版，[SmilesDrawer](https://github.com/reymond-group/smilesDrawer)则负责理解原子连接关系并生成二维结构图。

现在，在Markdown中写一段`smiles`代码块，页面就会把其中的分子或反应SMILES渲染成SVG，整个过程在浏览器端完成。

## 基本用法

在Markdown中使用`smiles`标记代码块，并在其中写入SMILES即可。例如，咖啡因的写法如下：

````markdown
```smiles
CN1C=NC2=C1C(=O)N(C(=O)N2C)C
```
````

实际渲染效果为：

```smiles
CN1C=NC2=C1C(=O)N(C(=O)N2C)C
```

结构图右上角有一个“复制源码”按钮，点击即可复制原始SMILES字符串，方便读者直接粘贴到ChemDraw、PubChem或其他工具中使用。

## SMILES的结构表达

SMILES（Simplified Molecular Input Line Entry System）用一行字符串描述原子、化学键、环、支链和立体化学。下表列出阅读后续示例所需的记号：

| 写法 | 含义 |
| --- | --- |
| `C`、`N`、`O` | 脂肪族原子（碳可省略氢） |
| `c`、`n` | 芳香原子（小写） |
| `=`、`#` | 双键、三键（单键和芳香键省略） |
| `( )` | 支链 |
| 数字（如`C1...1`） | 环闭合标记 |
| `@`、`@@` | 手性中心 |
| `/`、`\` | 双键的顺反构型 |
| `.` | 分隔同一体系中的多个组分 |

这些记号可以组合成相当复杂的结构。下面通过多环天然产物和配位化合物观察它们如何协同描述化学信息。

### 多环骨架与连续手性中心：青蒿素

青蒿素含有稠环、桥环、过氧桥和多个手性中心，其结构远比一条直链复杂。[PubChem收录的异构SMILES](https://pubchem.ncbi.nlm.nih.gov/compound/68827)为：

```smiles
C[C@@H]1CC[C@H]2[C@H](C(=O)O[C@H]3[C@@]24[C@H]1CC[C@](O3)(OO4)C)C
```

其中，重复出现的`1`、`2`、`3`、`4`把链状文本连接成多个环；`@`和`@@`记录各手性中心的构型；末尾的`OO4`则参与构成青蒿素特征的过氧桥。渲染器会根据这些信息自动安排原子和化学键的位置。

### 羰基金属配合物

羰基金属配合物可以用金属–碳键把中心金属与羰基配体连接起来。例如，四羰基镍包含一个Ni中心和四个CO配体：

```smiles
[Ni](C=O)(C=O)(C=O)C=O
```

五羰基铁则在Fe中心周围连接五组CO：

```smiles
[Fe](C=O)(C=O)(C=O)(C=O)C=O
```

这里的主链与括号共同表达中心金属和配体的连接关系，`C=O`表示羰基中的碳氧双键。图形展示原子连接关系，四面体、三角双锥等配位几何则可以由文字进一步说明。

更多语法可以参考[Daylight的SMILES教程](https://www.daylight.com/dayhtml/doc/theory/theory.smiles.html)。

## 反应SMILES

反应SMILES使用`>`分隔反应物、反应条件和产物，同一个代码块就可以绘制完整反应式。

| 写法 | 含义 |
| --- | --- |
| `A.B` | 同一侧包含多个物种 |
| `A>>B` | A为反应物，B为产物，中间不指定反应条件 |
| `A>C>B` | A为反应物，C为反应条件或试剂，B为产物 |

### 按机理步骤书写Robinson增环

Robinson增环把Michael加成、分子内羟醛缩合和脱水串联起来，可以在一步操作中建立新的六元环。下面以2-甲基-1,3-环己二酮与甲基乙烯基酮生成Wieland–Miescher酮为例，用三个连续的反应代码块记录关键中间体。

**第一步：Michael加成。**两个羰基之间的酸性C–H在碱作用下形成亲核碳中心，与甲基乙烯基酮发生共轭加成，把含甲基酮的侧链引入环上：

```smiles
CC1C(=O)CCCC1=O.C=CC(C)=O>[OH-]>CC1(CCC(C)=O)C(=O)CCCC1=O
```

点号分隔两种反应物，`[OH-]`位于反应条件字段。产物`CC1(CCC(C)=O)C(=O)CCCC1=O`同时保留原来的二酮骨架和新的侧链羰基。

**第二步：分子内羟醛加成。**侧链甲基酮的α-碳形成烯醇盐，对原环上的一个羰基进行分子内进攻，形成新的碳–碳键和第二个六元环：

```smiles
CC1(CCC(C)=O)C(=O)CCCC1=O>[OH-]>CC1(CCC(=O)C2)C(=O)CCCC12(O)
```

产物中的`C12(O)`同时参与两组环闭合，表示桥环连接处带有羟基的碳。至此，开链侧链已经转化为双环酮醇中间体。

**第三步：脱水形成共轭烯酮。**β-羟基酮失去一分子水，形成与羰基共轭的碳碳双键：

```smiles
CC1(CCC(=O)C2)C(=O)CCCC12(O)>>CC12CCC(=O)C=C1CCCC2=O.O
```

最终产物是[Wieland–Miescher酮](https://pubchem.ncbi.nlm.nih.gov/compound/89262)，常用作萜类和甾体合成的中间体；产物侧的点号和`O`表示同时生成的水。

这种写法把机理组织成可检查的物质序列：每一步都明确给出反应物、条件和产物，环闭合编号则记录新骨架的形成。电子转移方向可以继续在步骤文字中说明，读者也能通过复制按钮逐段取出中间体结构。

## 实现原理

这套方案和本站的`mermaid`代码块遵循同一套设计：作者在Markdown中编写纯文本源码，页面脚本再把它渲染成图形。

Kramdown会把代码块转换为带有`language-smiles`类名的HTML元素。页面脚本读取元素的`textContent`作为SMILES源码，因此SMILES中的括号、方括号、斜杠和`#`都能原样传给解析器。解析和布局完成后，脚本用SVG结构图替换原代码块，同时保留原始源码供复制按钮使用；需要排错时，原始代码块也可以作为回退内容显示。

绘图库通过ES Module从CDN动态导入：

```javascript
const { default: SmilesDrawer } = await import(
    "https://cdn.jsdelivr.net/npm/smiles-drawer@2/dist/smiles-drawer.min.mjs"
);
```

加载是按需进行的：构建页面时，Liquid模板检查正文是否包含`language-smiles`代码块，只有包含时才会输出相关样式和脚本。脚本本身约197 KB（gzip后约59 KB），访问其他文章时不会产生这部分请求。同一篇文章中的多个结构图共用一个`SmiDrawer`实例，库只加载一次。

SMILES结构图与Mermaid图共用同一套图表外框和复制按钮逻辑，两种图可以出现在同一篇文章中，各自的库独立按需加载。

## 核心绘图调用

SmilesDrawer的[使用文档](https://reymond-group.github.io/smilesDrawer/getting-started/)提供Canvas和SVG两种输出。本站使用`SmiDrawer`向SVG绘制分子或反应，核心调用可以概括为：

```javascript
const drawer = new SmilesDrawer.SmiDrawer({
    width: 600,
    height: 400,
    scale: 1,
    bondLength: 24,
    fontSizeLarge: 10,
    fontSizeSmall: 4,
    padding: 20
});

drawer.draw(source, svg, "light");
```

`scale: 1`让图形按照设定键长和文字大小呈现，避免简单分子被放大到整个画布；`bondLength`与字体选项控制结构的实际尺度。CSS中的`max-width: 100%`则负责在窄屏上按比例缩小较大的结构或反应式。

`SmiDrawer.draw`接收原始SMILES，负责解析、自动布局和SVG绘制。传入分子SMILES时绘制结构式，传入包含`>`的反应SMILES时绘制反应式。本站的完整实现还通过成功与失败回调处理代码块替换，并添加`figure`外框、复制按钮和`aria-label`等无障碍属性，代码位于布局文件`_layouts/post.html`。

## 小结

` ```smiles `代码块让分子结构和反应式以纯文本形式保存在文章源码中，可 diff、可复制、按需渲染。日常写作时，一行SMILES就能完成结构与反应展示；需要精确控制原子坐标和视觉排版时，也可以继续使用专业化学绘图软件生成的图片。
